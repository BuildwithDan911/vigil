About Vigil for IRIS for Health

Vigil was built for the InterSystems Programming Contest: AI Agents in Interoperability Workflows. It solves post-discharge diagnostic handoffs by combining an InterSystems IRIS for Health interoperability production with an AI Hub decision agent governed by a deterministic safety floor.

InterSystems Platform Integration Highlights

  • Community Idea DPI-I-689: Visual Trace integration logging agent prompt versions, token consumption, latency, and refusal telemetry.
  • Production Extension (PEX): Java/.NET operation verifying abnormality flags independently from Python rules.
  • Custom Adapter: Vigil.Adapter.NightShiftInbound driving the simulated hospital clock.
  • Workflow Engine: Native VigilApprovers task queue with portal inbox integration.
  • Vector Case Memory: Similar past case recall for clinical reassurance.
